# Administración de Debian 13
## Proyecto Linux - Grupo 5

### Sistema operativo
Debian 13 Trixie instalado en VirtualBox.

### Usuarios y grupos
- adminsys: administrador con permisos sudo.
- tecnico: pertenece al grupo soporte.
- visitante: pertenece al grupo web.

### Directorios
- /proyecto/datos
- /proyecto/web
- /proyecto/scripts
- /proyecto/capturas

### Permisos
Se configuraron permisos 2770 con SGID para
mantener la herencia de grupos.

Se comprobaron los accesos de los usuarios
tecnico y visitante.

### Herramientas instaladas
- Git
- Docker Engine
- Docker Compose

### GitHub
Se configuró la autenticación SSH y se clonó
el repositorio privado del Grupo 5.
